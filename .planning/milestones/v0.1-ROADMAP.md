## Overview

This roadmap delivered a hardened compile environment integration, codebase hygiene, architecture refactoring, and framework resilience improvements to the EmbedAgent agent core. Starting with code hygiene to establish a clean foundation, we integrated compiler detection and build execution, refactored monolithic classes into maintainable services, and finally layered on checkpointing, caching, and resilience features.

## Milestone Summary

**Key Decisions:**

- Decision: Code hygiene must precede feature work (Phase 1 before 2-4)
- Decision: Python 3.8 stdlib only for compile environment (subprocess, re, json, shlex)
- Decision: Facade + Strategy patterns with manual dependency injection for architecture refactor
- Decision: Git stash-based snapshots over file copies for lightweight rollback
- Decision: Threading-based concurrency for streaming build execution (Python 3.8 compatibility)
- Decision: Manual DI container over external framework (minimal dependency surface)

**Issues Resolved:**

- Fixed 44 bare `except Exception:` blocks across 16 source files
- Replaced all `datetime.utcnow()` with timezone-aware equivalents
- Eliminated global mutable state (MODE_REGISTRY, _DEFAULT_SANITIZER, _inprocess_adapter)
- Achieved zero deprecation warnings in test output
- Established service extraction pattern for future refactors

**Issues Deferred:**

- QueryEngine line count target (<500 lines) — actual ~1560 lines due to tight coupling; deferred to future architecture work
- L3 projection cache placeholder — full implementation requires projection_db schema changes
- TurnOrchestrator special cases (ask_user, propose_mode_switch) — remain in QueryEngine

**Technical Debt Incurred:**

- Some workflows reference `gsd-sdk` which is not available in this environment
- Nyquist compliance missing for Phases 2-4 (only Phase 1 has VALIDATION.md)
- L3 projection cache is a placeholder
