# Milestone v0.2: GUI & Harness Experience Refactor

**Started:** 2026-05-03
**Status:** ACTIVE

## Overview

Transform EmbedAgent's user experience to match industry-leading agent coding tools (Claude Code, Codex, Roo Code) by refactoring session persistence, conversation flow, and mode execution models.

## Reference Engineering

Deep analysis of 7 reference projects conducted 2026-05-03:
- Claude Code — TUI conversation patterns, JSONL transcript, 6-state tool lifecycle
- Codex — ThreadItem model, item lifecycle events, HistoryCell trait
- Roo Code — Auto-approval, git checkpoints, diff view, consecutive mistake limit
- OpenCode — CLI/TUI session management
- GSD — Wave execution, file-based state
- Superpowers — Plan execution, verification gates
- OpenHands — Anti-patterns (multi-agent complexity, database dependency)

Research report: `.planning/phases/01-ui-ux-harness-research/01-RESEARCH.md`
Architecture spec: `.planning/notes/session-architecture-v2-spec.md`

## Key Decisions

| ID | Decision | Rationale |
|----|----------|-----------|
| D-07 | Flat Item[] over nested Turn→Step→ToolCall | Codex/Cline pattern; simpler frontend consumption |
| D-08 | Schema-v2 JSONL transcript | Typed messages, parentUuid chain, item lifecycle events |
| D-09 | Best-effort session restore | Single corrupted record should not block recovery |
| D-10 | Mode as permission contract only | Remove unconditional workflow injection |

## Risks

| Risk | Mitigation |
|------|------------|
| Format upgrade breaks existing sessions | Maintain schema_version=1 read capability |
| Frontend/Backend format mismatch | Provide compatibility layer; migrate incrementally |
| Performance with large item counts | Virtual scrolling, pagination, incremental updates |

## Success Criteria

1. Session restore success rate > 95%
2. Build mode "hi" → normal chat, no workflow trigger
3. Complex tasks run 20+ steps without interruption
4. Tool calls display inline with lifecycle states
5. File diffs show inline with line numbers and syntax highlighting
6. Win7 offline environment fully functional
