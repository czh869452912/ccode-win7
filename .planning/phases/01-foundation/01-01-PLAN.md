   ```python
   return datetime.utcnow().replace(microsecond=0).isoformat() + "Z"
   ```
   to:
   ```python
   return datetime.now(timezone.utc).replace(microsecond=0).isoformat().replace("+00:00", "Z")
   ```
   
   **Rationale (per review):** `.replace("+00:00", "Z")` is safer than `strftime` because it preserves the ISO 8601 format exactly while only changing the timezone suffix. The `isoformat()` method on a timezone-aware datetime produces `"2024-01-15T10:30:00+00:00"`, so replacing `"+00:00"` with `"Z"` yields the exact original format `"2024-01-15T10:30:00Z"`.
   
   **Alternative (if review concern about replace):**
   ```python
   return datetime.now(timezone.utc).replace(microsecond=0).strftime("%Y-%m-%dT%H:%M:%SZ")
   ```
   Either approach is acceptable; the `.replace()` approach is primary.
