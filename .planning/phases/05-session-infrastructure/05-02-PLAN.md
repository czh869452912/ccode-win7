2. Update `SessionRestorer.restore()` signature:
   ```python
   def restore(self, events: List[Dict[str, Any]], best_effort: bool = False) -> SessionRestoreResult:
   ```

3. Add `_should_skip_error(error_reason: str) -> bool` helper:
   ```python
   def _should_skip_error(self, error_reason: str) -> bool:
       """Determine if an error is skippable in best_effort mode.
       
       Non-skippable errors (always stop):
       - Empty events list
       - Fundamental session structure corruption
       
       Skippable errors:
       - turn_mismatch, step_mismatch
       - duplicate IDs
       - missing parent message
       - tool result without tool call
       - stale interaction
       - identity mismatches
       """
       non_skippable = {"empty_transcript"}
       return error_reason not in non_skippable
   ```

4. Modify the main event loop to support skipping:
   Replace the current pattern where each validation failure immediately breaks:
   ```python
   # BEFORE (strict):
   if message_error:
       consumed_event_count = index
       stop_reason = message_error
       break
   
   # AFTER (best_effort aware):
   if message_error:
       if best_effort and self._should_skip_error(message_error):
           skipped_count += 1
           skip_reasons.append({
               "index": index,
               "event_type": event_type,
               "reason": message_error,
               "event_id": str(event.get("event_id", "")),
           })
           continue  # skip this record, try next
       else:
           consumed_event_count = index
           stop_reason = message_error
           break
   ```

5. Apply the same pattern to ALL validation points in the restore loop:
   - `step_started` turn/step mismatch, duplicate step_id
   - `tool_call` without active step, turn/step mismatch, duplicate call_id
   - `tool_result` missing tool call, missing parent message, duplicate message_id, turn/step mismatch, identity mismatch
   - `pending_interaction` turn/step mismatch, missing interaction_id, stale interaction, duplicate interaction_id
   - `pending_resolution` without pending, turn/step mismatch, identity mismatch
   - `content_replacement` target mismatch
   - `compact_boundary` invalid preserved segment, duplicate boundary_id
   - `loop_transition` turn/step mismatch
   - `message` events: parent missing, duplicate message_id, turn mismatch, step mismatch, unknown role

6. Update the return statement to include skip counts:
   ```python
   return SessionRestoreResult(
       session=session,
       current_mode=current_mode,
       transcript_event_count=len(events),
       consumed_event_count=consumed_event_count,
       stop_reason=stop_reason,
       skipped_count=skipped_count,
       skip_reasons=skip_reasons,
   )
   ```

7. Add logging for skipped records (import logging if not already):
   ```python
   import logging
   _LOG = logging.getLogger(__name__)
   
   # In skip branch:
   _LOG.warning(
       "Session restore skipped record %d (type=%s, id=%s): %s",
       index, event_type, event.get("event_id", ""), message_error
   )
   ```
