Create `src/embedagent/strategies/circuit_breaker.py` implementing a standard circuit breaker pattern:

**Class: CircuitBreaker**

States:
- `CLOSED` (normal operation)
- `OPEN` (failing fast)
- `HALF_OPEN` (testing recovery)

Constructor:
- `__init__(self, failure_threshold: int = 5, recovery_timeout: float = 30.0, half_open_max_calls: int = 3)`
- `failure_threshold`: consecutive failures before opening
- `recovery_timeout`: seconds to wait before transitioning to HALF_OPEN
- `half_open_max_calls`: successful calls in HALF_OPEN needed to close

Methods:
1. `call(self, func: Callable, *args, **kwargs) -> Any`:
   - If state is OPEN and recovery_timeout not elapsed: raise `CircuitBreakerOpenError`
   - If state is OPEN and timeout elapsed: transition to HALF_OPEN
   - Execute func
   - On success: record success, transition CLOSED if in HALF_OPEN
   - On failure: record failure, transition OPEN if threshold reached
   - Return func result

2. `record_success(self)` - increment success counter, reset failure count
3. `record_failure(self)` - increment failure counter, check threshold
4. `reset(self)` - force to CLOSED state

Properties:
- `state` (str): current state name
- `failure_count` (int): current consecutive failures
- `success_count` (int): successes in HALF_OPEN
- `last_failure_time` (Optional[float]): timestamp of last failure

**Exception class: CircuitBreakerOpenError**
- Raised when circuit is OPEN and call is attempted

**Update `src/embedagent/strategies/__init__.py`:**
- Add `from embedagent.strategies.circuit_breaker import CircuitBreaker, CircuitBreakerOpenError`

**Python 3.8 constraints:**
- Use `typing.Callable`, `typing.Any`, `typing.Optional`, `typing.Tuple`
- No dataclasses with `slots`, no `|` syntax
- Use `time.time()` for timestamps
