  <files>src/embedagent/services/shadow_git.py, src/embedagent/services/__init__.py</files>
  <action>
Create `src/embedagent/services/shadow_git.py` implementing the ShadowGitSnapshot service:

**Class: ShadowGitSnapshot**

Constructor:
- `__init__(self, workspace: str, snapshot_dir: str = ".embedagent/snapshots")`
- Stores workspace path and snapshot directory path

Methods:
1. `create_snapshot(self, reason: str = "") -> str`:
   - Generate unique snapshot ID using `uuid.uuid4().hex[:8]` + timestamp
   - Create snapshot metadata (id, created_at, reason, branch, commit_hash)
   - Use `git stash push --include-untracked --message "shadow:{snapshot_id}:{reason}"` to capture workspace state
   - Store metadata JSON in `{snapshot_dir}/{snapshot_id}.json`
   - Return snapshot_id

2. `restore_snapshot(self, snapshot_id: str) -> bool`:
   - Read metadata file
   - Pop the corresponding stash entry using `git stash list` to find match by message
   - Apply stash with `git stash pop stash@{N}`
   - Return True on success, False on failure

3. `list_snapshots(self) -> List[Dict[str, Any]]`:
   - Read all `.json` files in snapshot_dir
   - Return list of metadata dicts sorted by created_at descending

4. `delete_snapshot(self, snapshot_id: str) -> bool`:
   - Remove metadata file
   - Drop corresponding stash entry if found
   - Return True on success

5. `cleanup_old_snapshots(self, max_age_hours: int = 24) -> Dict[str, int]`:
   - Delete snapshots older than max_age_hours
   - Also drop corresponding stash entries
   - Return {"deleted": N, "retained": M}

**Error handling:**
- All git commands must check for git repository (`.git` exists)
- Raise `ToolError` with descriptive messages for git failures
- Log warnings on non-fatal errors

**Update `src/embedagent/services/__init__.py`:**

- Use `datetime.now(timezone.utc)` (not `datetime.utcnow()` — per Phase 1 hygiene)
- No walrus operator, no match statements

- Import `ShadowGitSnapshot` from `embedagent.services.shadow_git`
- In the `build_tools()` function, before `_write_file()` and `_edit_file()` execute:
  - Create a `ShadowGitSnapshot(ctx.workspace)` instance
  - Call `.create_snapshot(reason="pre_edit:{tool_name}")` IF the file already exists (not for new file creation)
  - The snapshot should be created BEFORE the modification is applied
  - Wrap in try/except so snapshot failure doesn't block the actual operation (log warning)
