Create `src/embedagent/strategies/diff_engine.py` implementing a multi-search-replace diff engine:

**Dataclass: DiffBlock**
- `old_text: str`
- `new_text: str`
- `expected_start_line: Optional[int] = None` (0-indexed, for disambiguation)
- `fuzzy: bool = True` (allow whitespace normalization)

**Class: MultiSearchReplaceDiffEngine**

Constructor:
- `__init__(self, fuzzy_threshold: float = 0.85)`
- `fuzzy_threshold`: minimum similarity score (0.0-1.0) for fuzzy matches

Methods:

1. `apply_diff(self, content: str, blocks: List[DiffBlock]) -> Tuple[str, List[Dict[str, Any]]]`:
   - Validate blocks (no overlapping old_text regions)
   - Sort blocks by expected_start_line (if provided) or by first occurrence position
   - For each block:
     - Find match using `_find_match()`
     - If found: apply replacement, record success
     - If not found: record failure, continue with other blocks
   - Return `(updated_content, results)` where results is list of dicts with `block_index`, `status` ("applied"|"failed"|"skipped"), `line_number`, `message`

2. `_find_match(self, content: str, block: DiffBlock) -> Optional[Tuple[int, int]]`:
   - **Exact match:** Try `content.find(block.old_text)`
   - If exact match found and unique (or matches expected_start_line): return (start, end)
   - **Fuzzy match:** If fuzzy=True and no exact match:
     - Normalize whitespace in both content and old_text (collapse multiple spaces/newlines, strip leading/trailing)
     - Find candidate regions using line-based matching
     - Compute similarity ratio using `difflib.SequenceMatcher`
     - Return best match above threshold
   - **Disambiguation:** If multiple matches found:
     - Use `expected_start_line` to select the correct one
     - If no expected_start_line, prefer first occurrence
   - Return `None` if no suitable match

3. `_validate_no_overlap(self, blocks: List[DiffBlock], content: str) -> List[str]`:
   - Check that replacement regions don't overlap
   - Return list of error messages for overlapping blocks

4. `preview_diff(self, content: str, blocks: List[DiffBlock]) -> List[Dict[str, Any]]`:
   - Same as apply_diff but doesn't modify content
   - Returns predicted results without side effects

**Helper functions:**
- `_normalize_whitespace(text: str) -> str`: collapse multiple whitespace chars to single space, strip
- `_line_number(content: str, position: int) -> int`: compute 0-indexed line number from character position

**Error handling:**
- `DiffError` exception class for unrecoverable errors
- All failures recorded in results, not raised (partial application supported)

**Python 3.8 constraints:**
- Use `typing.List`, `typing.Tuple`, `typing.Optional`, `typing.Dict`
- Use `dataclasses.dataclass` for DiffBlock
- Use `difflib.SequenceMatcher` for fuzzy matching
- No external dependencies

**Update `src/embedagent/strategies/__init__.py`:**

**In `src/embedagent/tools/file_ops.py`:**

1. **Import diff engine:**

2. **Update `_edit_file` handler:**
   - Keep existing parameters: `path`, `old_text`, `new_text`
   - Add optional parameter: `blocks` (list of dicts with `old_text`, `new_text`, optional `expected_start_line`)
   - If `blocks` provided: use multi-block diff
   - If only `old_text`/`new_text` provided: wrap in single DiffBlock for backward compatibility
   
   Implementation:
   ```python
   def _edit_file(arguments):
       path = ctx.resolve_path(str(arguments["path"]))
       if not os.path.isfile(path):
           raise ToolError("只能修改已存在的文本文件。")
       
       content, newline_style, encoding = ctx.read_text(path)
       engine = MultiSearchReplaceDiffEngine()
       
       # Build blocks from arguments
       blocks = []
       if "blocks" in arguments and arguments["blocks"]:
           for block_data in arguments["blocks"]:
               blocks.append(DiffBlock(
                   old_text=str(block_data["old_text"]),
                   new_text=str(block_data["new_text"]),
                   expected_start_line=block_data.get("expected_start_line"),
                   fuzzy=block_data.get("fuzzy", True),
               ))
       else:
           old_text = str(arguments["old_text"])
           new_text = str(arguments["new_text"])
           if not old_text:
               raise ToolError("old_text 不能为空。")
           blocks.append(DiffBlock(old_text=old_text, new_text=new_text))
       
       updated_content, results = engine.apply_diff(content, blocks)
       
       # Check results
       failed = [r for r in results if r["status"] != "applied"]
       if failed:
           error_msg = "; ".join("Block %d: %s" % (r["block_index"], r["message"]) for r in failed)
           raise ToolError("编辑失败：%s" % error_msg)
       
       ctx.write_text(path, updated_content, newline_style, encoding)
       
       applied_count = len([r for r in results if r["status"] == "applied"])
       return Observation(
           tool_name="edit_file",
           success=True,
           error=None,
           data={
               "path": ctx.relative_path(path),
               "encoding": encoding,
               "replaced": True,
               "applied_blocks": applied_count,
               "line_count": updated_content.count("\n") + (1 if updated_content else 0),
           },
       )
   ```

   - Mark `blocks` as alternative to old_text/new_text for advanced use
   - Description update: mention multi-block support

**Python 3.8 constraints:**
