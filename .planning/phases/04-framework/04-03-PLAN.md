Create `src/embedagent/strategies/tool_cache.py` implementing a 3-tier cache:

**Enum: CacheTier**
- `L1_MEMORY = "l1_memory"`
- `L2_DISK = "l2_disk"`
- `L3_PROJECTION = "l3_projection"`

**Class: CacheEntry**
- `value: Observation`
- `created_at: float` (timestamp)
- `ttl_seconds: int`
- `tier: CacheTier`
- `hit_count: int = 0`

**Class: ToolResultCache**

Constructor:
- `__init__(self, tool_result_store: Optional[Any] = None, max_memory_entries: int = 100, default_ttl_seconds: int = 300)`
- `max_memory_entries`: LRU cap for L1
- `default_ttl_seconds`: default TTL (5 minutes)

Methods:

1. `get(self, action: Action, session_id: str = "") -> Optional[Observation]`:
   - Compute cache key from `(action.name, _hash_arguments(action.arguments), session_id)`
   - **L1 Lookup:** Check in-memory dict; if hit and not expired, increment hit_count, return
   - **L2 Lookup:** Check tool_result_store for serialized result; if found, deserialize, populate L1, return
   - **L3 Lookup:** Check projection_db for matching result reference; if found, hydrate, populate L1+L2, return
   - Return None if not found in any tier

2. `put(self, action: Action, observation: Observation, session_id: str = "", ttl_seconds: Optional[int] = None) -> None`:
   - Compute cache key
   - Store in L1 memory (evict oldest if > max_memory_entries)
   - Store in L2 disk via `tool_result_store.write_json()`
   - Update L3 projection reference if projection_db available

3. `invalidate(self, action_name: Optional[str] = None, session_id: Optional[str] = None) -> int`:
   - Remove matching entries from L1
   - Remove matching entries from L2 (via cleanup_unreferenced or selective deletion)
   - Return count of invalidated entries

4. `invalidate_expired(self) -> int`:
   - Scan L1 and remove expired entries
   - Return count removed

5. `stats(self) -> Dict[str, int]`:
   - Return `{"l1_size": N, "l2_size": M, "l3_size": P, "total_hits": Q}`

**Cache key generation:**
- `_hash_arguments(arguments: Dict[str, Any]) -> str`:
  - Serialize arguments to canonical JSON (sorted keys)
  - Return SHA1 hex digest (first 16 chars)

**TTL checking:**
- `_is_expired(entry: CacheEntry) -> bool`:
  - `time.time() > entry.created_at + entry.ttl_seconds`

**Python 3.8 constraints:**
- Use `typing.Dict`, `typing.List`, `typing.Optional`, `typing.Tuple`, `typing.Any`
- Use `collections.OrderedDict` for LRU ordering in L1 (or manual timestamp tracking)
- No `functools.lru_cache` decorator (we need custom eviction)
- Use `json.dumps(..., sort_keys=True)` for canonical serialization

**Update `src/embedagent/strategies/__init__.py`:**
- Add exports for `ToolResultCache`, `CacheTier`, `CacheEntry`

Integrate ToolResultCache into the tool execution flow in ToolRuntime.

**In `src/embedagent/tools/runtime.py`:**

1. **Add cache field:**
   - Import `ToolResultCache` from `embedagent.strategies.tool_cache`
   - Add optional `cache` parameter to `ToolRuntime.__init__`
   - If not provided, create `ToolResultCache(tool_result_store=self.tool_result_store)`
   - Store as `self._cache`

2. **Add cache-aware execution method:**
   - Create `execute_with_cache(self, action_name: str, arguments: Dict[str, Any], session_id: str = "", use_cache: bool = True) -> Observation`:
     - If `use_cache` is False, call `self.execute()` directly and return
     - Build `Action` object from action_name + arguments
     - Call `self._cache.get(action, session_id)`
     - If cache hit, return cached observation
     - If cache miss, call `self.execute(action_name, arguments)` to get observation
     - If observation.success is True, call `self._cache.put(action, observation, session_id)`
     - Return observation

3. **Update existing `execute_with_interrupt`:**
   - Check if it already calls `execute()` — if so, add optional `use_cache` parameter
   - Pass through to cache-aware execution when appropriate
   - Ensure stop_event still interrupts execution (cache lookup is fast enough to not need interruption)

4. **Add cache invalidation hooks:**
   - After `write_file` or `edit_file` operations succeed, invalidate cache entries for read_file/grep_text on affected paths
   - After `run_recipe` succeeds, invalidate recipe-related caches
   - This can be done by adding an `_invalidate_related_cache(action_name, arguments)` helper

**Python 3.8 constraints:**
- Maintain backward compatibility: `execute()` signature unchanged
- New `execute_with_cache()` is additive only
- Default behavior: caching enabled but only for read-only tools (determine via `tool_capabilities` lookup)
